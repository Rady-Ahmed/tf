# AL RADY FAMILY LEGACY — المنصة الرقمية الموحدة لعائلة آل راضي

> **«أَصْلُهَا ثَابِتٌ وَفَرْعُهَا فِي السَّمَاءِ»**

منصة ويب متكاملة وتفاعلية توثق تاريخ وأنساب عائلة **آل راضي** بقرية **شارونة** (أواخر القرن الثامن عشر الميلادي ١٧٠٠م)، وتجمع بين حفظ الأنساب، وموسوعة الأفراد، وأرشيف الأجداد (أثر لا يغيب)، ونظام المساهمات المجتمعية الذكي، ولوحة تحكم مركزية للأدمن للاعتماد والنشر.

---

## 🌟 مميزات المنصة

1. **شجرة العائلة التفاعلية (5 أوضاع عرض ديناميكية):**
   - الشجرة الرأسية الهرمية مع خطوط الربط للأنساب
   - شبكة البطاقات التفاعلية
   - عزل الفروع العائلية الكبرى (عبدالصمد، حمد، وقاد)
   - مسار سلسلة النسب «من راضي إليك»
   - الأجيال الزمنية (١ إلى ١٠)
   - بحث لحظي بالاسم والمعرف الداخلي
   - تكبير، تصغير، وملاءمة للشاشة

2. **موسوعة أفراد العائلة (Encyclopedia):**
   - ملف توثيقي شامل لكل فرد من الـ ٧٣ فردًا الموثقين
   - عرض سلسلة النسب، الوالد، الأبناء، والإخوة
   - الموطن، المهنة، تاريخ الميلاد والوفاة، والسيرة الذاتية
   - زر مباشر «ساهم بتعديل بيانات أو إضافة صورة لهذا الفرد»
   - رابط مشاركة لكل فرد

3. **أثر لا يغيب (أرشيف الأجداد والراحلين):**
   - قسم وقور لتكريم الأجداد والآباء الراحلين بالدعاء والرحمة
   - توثيق السير والذكريات والمآثر

4. **ذاكرة وتاريخ آل راضي:**
   - توثيق استقرار العائلة بقرية شارونة بشرق النيل أواخر القرن الثامن عشر
   - تاريخ المشيخة والعمودية
   - أرشيف الوثائق التاريخية والمخطوطات

5. **نظام المساهمات الذكي «ساهم في حفظ تاريخ العائلة»:**
   - مفتوح لجميع أفراد العائلة دون الحاجة لتسجيل دخول
   - يدعم ١١ نوعًا من المساهمات (فرد جديد، تعديل، تصحيح، صور، وثائق، قصص، ذكريات...)
   - نموذج يتغير ذكيًا حسب نوع المساهمة
   - رفع الصور والمستندات (حتى ٥ ميجابايت)
   - توليد رقم مرجعي فريد لكل طلب (مثال: `RADY-REQ-2026-XXXX`)
   - لا ينشر أي تعديل تلقائيًا إلا بعد اعتماد الأدمن

6. **نظام تتبع المساهمات:**
   - إمكانية تتبع حالة المساهمة بالرقم المرجعي (جديد، قيد المراجعة، يحتاج معلومات، معتمد، مرفوض) مع ملاحظات الإدارة.

7. **لوحة تحكم مركزية للأدمن (المهندس راضي أحمد):**
   - تسجيل دخول آمن (كلمة المرور الافتراضية: `rady2026`)
   - طابور مراجعة المساهمات مع عداد لحظي
   - فاحص المقارنة البصري المزدوج (Side-by-Side Diff) بين البيانات الحالية والبيانات المقترحة
   - أزرار التحكم: «اعتماد ونشر فوري»، «تعديل قبل النشر»، «رفض الطلب»
   - إدارة الأفراد وإضافة أفراد جدد مباشرة
   - سجل التراجع واسترجاع النسخ السابقة (Rollback)
   - سجل تدقيق العمليات (Activity Audit Logs)

## 🛠️ التقنيات المستخدمة

- **Frontend:** React 19 + TypeScript + Vite 6
- **Styling:** Vanilla CSS متقدم بهوية بصرية مميزة (Emerald Green, Antique Gold, Ivory, Dark Obsidian) ودعم كامل للغة العربية (RTL) مع خطوط `Amiri` و `Readex Pro` و `IBM Plex Sans Arabic`.
- **Database:** Supabase PostgreSQL مع Row Level Security (RLS) ومخطط مهيأ بالكامل، ونظام تخزين محلي تفاعلي (Local Reactive Store) يعمل فورًا بدون إعدادات مسبقة.
- **Icons & Effects:** Lucide React + Canvas Confetti.

## 🗄️ ربط قاعدة بيانات Supabase (اختياري للإنتاج)

1. أنشئ مشروع جديد على [Supabase](https://supabase.com/).
2. افتح **SQL Editor** في Supabase ونفّذ ملفات الـ Migration الموجودة في المجلد:
   - `supabase/migrations/20261031_001_initial_schema.sql` (إنشاء الجداول والـ RLS والـ Indexes)
   - `supabase/migrations/20261031_002_seed_data.sql` (استيراد الـ ٧٣ فردًا وكافة العلاقات والفروع)
3. انسخ ملف `.env.example` إلى `.env` وضع مفاتيح مشروعك:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```
4. أعد تشغيل التطبيق وسيقوم بالاتصال المباشر بقاعدة البيانات المركزية.
